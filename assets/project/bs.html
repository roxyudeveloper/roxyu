About Black Spider Evolution

Black Spider Evolution adalah Expert Advisor untuk MetaTrader 5 yang menggabungkan strategi Martingale Grid dengan Smart Hedging System. EA ini dirancang untuk memanfaatkan pergerakan harga dengan pendekatan averaging yang dikombinasikan dengan hedging otomatis untuk meminimalisir drawdown.

Core Features

Smart Hedging System

Hedge otomatis diaktifkan setelah mencapai layer tertentu. Posisi hedge akan terus di-averaging hingga TP/BE/Trail kena.

Loop Infinity Mode

Cycle berulang tanpa henti. Main → Hedge → Main baru → Hedge baru. Trading otomatis 24/5 tanpa intervensi manual.

Dual Order Modes

Martingale (multiplier 1.1x) atau Step Mode (incremental 0.01) untuk menentukan lot setiap layer.

Break Even System

Break even terpisah untuk Main dan Hedge dengan trigger profit dollar dan jarak BE yang dapat diatur.

Trailing Stop

Trailing stop terpisah setelah BE aktif untuk mengunci profit maksimal.

Graceful Shutdown

Grace period saat jam trading habis. Posisi tetap bisa averaging dan close via BE/Trail, tanpa open baru.

Trading Modes

MARTINGALE

STEP MODE
